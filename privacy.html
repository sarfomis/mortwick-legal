Privacy Policy

Last updated: 2 October 2026

1. Who we are

Mortwick Publisher is a private tool run by one individual for publishing their own videos on their own TikTok account. It has no other users.

2. Data we handle

When the owner connects the tool to TikTok, TikTok gives it an access token for the owner's account. The tool uses this token only to upload and publish the owner's own videos. It does not read, collect or store data about any other TikTok user.

3. Where it is stored

The access token is stored in a private file on the owner's own computer. It is not shared with anyone and not uploaded to any server.

4. Sharing and selling

We do not share, sell or transfer any data to third parties.

5. Deleting data

The owner can revoke access at any time from TikTok (Settings and privacy, Security and permissions, Apps and websites) and delete the local token file.

6. Contact

Open an issue on github.com/sarfomis/mortwick-legal.
